# Governments on Superintelligence
What do government officials say about AGI, its risks, and policy approaches to it? We collect quotes with metadata from official source into a database, and analyze. 

This repository contains the website displaying the data, for data collection see the [accompanying repository](https://github.com/lennart-finke/governments-on-superintelligence-data).

To use this, obtain a data payload from the data collection repository, then serve this directory, say with `python -m http.server`.
